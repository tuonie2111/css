TRAVEL GALLERY - HTML/CSS ASSIGNMENT

Files:
- index.html
- nature.html
- cities.html
- style.css

Requirements covered:
1. Three HTML pages.
2. At least one image on every page.
3. Nature page contains six images.
4. Skip to Main Content link uses position and :focus.
5. Navigation uses Flexbox and several CSS properties.
6. Images use border, padding, border-radius (box model).
7. CSS Grid is used on the nature gallery.
8. CSS Flexbox is used on the navigation and city gallery.
9. :hover is used with transform and box-shadow.
10. :nth-child() is used to vary image border radii.
11. Responsive layout is included.

Validation:
- W3C HTML Validator: https://validator.w3.org/
- WAVE: https://wave.webaim.org/

Important:
The images use remote Unsplash URLs. If your course requires images that you personally own, replace the image URLs with your own image files and keep the alt text.
